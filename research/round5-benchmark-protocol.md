## 1. 预注册判定标准（先于一切运行锁定）

### 1.1 主判据：区分度

- **定义**：任务级条件间分歧——同一任务在不同条件下（至少一对条件）成败不一致，且该任务
  三条件×重复的成败矩阵非全同。
- **INFORMATIVE 门槛**：≥ 4/12 任务出现条件间分歧（沿用 v2 敏感性判据的量级）。
- **明确排除**：弱模型总体失败率 > 0 **不构成**区分度。全员失败与全员通过同样是零信息。
- 结果分级：`INFORMATIVE`（≥4 分歧）/ `PARTIAL`（1–3 分歧）/ `CEILING/FLOOR-LIMITED`（0 分歧）。

### 1.2 成本红线

- **基线明确指定为 controlB**（三行脚手架），不是 controlA（裸跑）。
- 红线：质量（成功率）不显著低于 controlB 的前提下，treatment 的 token 总量与工具调用总次数
  均不超过 controlB 中位数的 **120%**。
- 判定：超线且质量无差异 → 记为**负收益案例**（进失败日志），不因事后解释放宽。

### 1.3 结果分支（降级规则，预注册）

| 分支 | 触发条件 | 处置 |
|---|---|---|
| A：语料太易 | 弱模型在 v2 语料 12 任务全对 | 启用公开基准子集（冒烟通过者）重跑主判据，**仅一次** |
| B：方法负证据 | 弱模型确有失败（≥3 任务失败）但三条件零分歧 | `methods/experimental/` 方法卡（capability-calibration、verify-planner、signal-extraction、execution-protocol、multi-agent-orchestration、decision-certainty-cost）中**经本轮臂间实际承载的**降级为 `rejected`，新增失败日志条目（F18） |
| C：有区分度 | ≥4 任务分歧 | 进入增益判定（第六轮设计），本轮方法卡保持 experimental |

分支 B 的限定语「经本轮臂间实际承载的」：只降级本轮 treatment 臂真正执行到的机制对应的方法卡；
纯内部机制（未经行为路径承载的）不在本轮处置范围内，避免一次实验杀死未受试的方法。

### 1.4 统计分析计划

- 任务级：3×3（条件×成败）或 2×2（treatment vs controlB）Fisher 精确检验；每格 3 次重复下，
  只有 3:0 级别的干净分歧能到 p≈0.05——**功效诚实声明**：默认设计只能检测大效应；每格 5 次
  （预算 ×1.67）可将可检测效应下探一档，作为预算充足时的可选升级。
- 汇总级：报告全部分析结果含不显著者；不做事后子集挑选；多重比较按任务数做 Holm 校正的
  敏感性附注（主判定以预注册门槛 1.1 为准，不以校正后 p 值重定门槛）。

## 2. 因素结构

### 2.1 被试模型（弱模型）

- **主候选**：GLM-5.3-flash（项目目标 profile 已点名）。
- **备选**（主候选不可用或不落判别带时按序尝试）：Qwen3-8B 级开源小模型、其他厂商 flash/mini 档。
- **入选标准（Phase 1 冒烟裁定）**：v2 语料裸跑解出率落在 **20%–70%** 判别带内。

### 2.2 条件臂

| 臂 | 内容 | 说明 |
|---|---|---|
| controlA | 裸任务文本 | 沿用 v2 `conditions.json` 模板 |
| controlB | 三行最小脚手架 | 同 v2，成本红线基线 |
| treatment | 注入冻结 `SKILL.md` 快照 | 复用 v2 冻结资产（SHA-256 `a5a52f…c98`），**不读活动仓库** |
| controlC（可选，预算允许时） | 与 treatment **等长度**的无信息 placebo 文本 | 用于把「内容效应」与「长度效应」分开——v2 中 treatment 输入 9345 字符 vs controlB 极短，若出现差异必须排除「只是提示词更长」这一混淆解释。若启用，1.1/1.2 的判定不因第四臂改变 |

### 2.3 重复与规模

- 默认：12 任务 × 3 臂 × 3 重复 = **108 runs**（v2 语料主实验）。
- 预算下限：×2 重复 = 72 runs（功效进一步下降，需在报告中声明）。
- 公开基准子集规模见 §3；每基准独立计数。
- 运行顺序：新随机 seed，任务×臂×重复分层随机；dispatch 纪律沿用 v2（max 5 并行、逐 run
  全新工作区、评估器绝不进入工作区、dispatcher 文本逐字节一致）。

## 3. 语料组合（批次化，逐批 gate）

| 批次 | 内容 | 规模（runs，按 3 臂×3 重复计） | 触发条件 | 主要目的 |
|---|---|---|---|---|
| 0 | v2 冻结 12 任务 | 108 | 必做 | 主判据 + 与 v2 强模型结果直接对照（跨模型泛化证据） |
| 1a | FollowBench 5 类型×各 1 条×L1–L5（25 prompt/臂） | 225 prompt 次（纯 API，无工作区） | 批次 0 出结果后即做 | **信号校准**：约束层级已知 → 直接测 `constraint_count`/`hidden_constraint` 自报失真率 |
| 1b | τ²-bench retail+airline 各 10 任务 | 180 | 同上 | 可靠性维度：pass^k 衰减 + 工具调用遥测 |
| 2a | Terminal-Bench 2.0 子集 10 任务 | 90 | 批次 1 完成且预算剩余 ≥40% | shell 全量 action 遥测 + 难度散布 |
| 2b | LegalBench / FinanceBench 各 20 题 + PRBench 子集 | ~200（每题 3 臂×1 重复；题库类不需要 3 重复，题间即重复） | 同上 | 专业领域覆盖 + 高风险推理（`error_cost` 信号） |
| 3 | SWE-bench Pro 子集 10 任务 / Vending-Bench 2 | 视预算 | 预算允许 | 重工程 / 长程一致性 |

**纳入/排除标准（对所有公开基准）**：

1. 冒烟 5–10 项，弱模型基线须落 20%–70% 判别带；不落则换档（如 Terminal-Bench 4.0→2.0）或排除。
2. 优先带 `-Verified` 的版本；已知可刷榜漏洞的基准（Berkeley RDI 2026-04 审计点名者）要么排除，
   要么自建评分器复现。
3. 需要本地评分器可复现（评分脚本随实验数据入库），不引用第三方榜单绝对值。
4. 污染防护：优先滚动更新版本（如 HLE-Rolling 思路）；冻结所选题单与版本哈希。

## 4. 遥测四项最小集（每 run 一个 `telemetry.json`）

```json
{
  "run_id": "...",
  "task_id": "...", "condition": "...", "repeat": 2,
  "actions": [{"ts": 0, "tool": "bash", "args_digest": "sha256:…", "status": "ok"}],
  "router_outputs": [{"strategy": "deep", "model_action": "keep",
                      "reasons": ["…"], "self_reported_signals": {"clarity": 0.4}}],
  "tokens": {"input": 0, "output": 0},
  "retries": 0,
  "action_loop_events": 0
}
```

- `actions`/`tokens`/`retries`：**所有臂**必收（这是 v2 的 0/36 缺口）。
- `router_outputs`：仅 treatment 臂（controlA/B 没有 router；这不影响臂间成本比较，成本比较用
  `actions`+`tokens`）。
- 宿主不暴露的字段如实记 `"UNMEASURABLE"`，**不造替代值**（沿用 v2 预注册纪律）。
- **F16 观测指标**（仅观测不修）：`action_loop_events` = 「声明将执行动作 X 后连续 3 轮无任何
  工具调用」的声明次数，从 transcript 自动扫描 + 人工抽检 10% 校准扫描器。

### 10.4 修正案 A-3（2026-10-24，终版分析前记录：失败按原因分层）

批次 0 逐任务诊断发现 provider 级 `HTTP 400 could not be rendered into a prompt` 失败（长注入
臂 23.7% vs 短注入臂 7.6%，p=0.0009）。预注册的 pass-rate 将其与行为失败混为一格，产生过一次
假阳性"认知差异"（p=0.025，分层后消失，见 F21）。修正：分析的一级口径改为
**pass / infra-error / behavioral-fail 三分**；infra-error 率本身作为独立结果报告（它是注入
长度等设计属性的真实成本计量）。功率冲刺（A-2 后追加的 10 重复/臂）因行为层天花板失去对象，
在 233 runs 处冻结。

### 10.3 修正案 A-2（2026-10-24，所有者授权：GLM-5.3-Flash 作为被试）
